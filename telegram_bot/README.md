# 🤖 Telegram-бот для кафе "Соль и Перец"

## Функции:
- 📦 Уведомления о заказах с кнопками управления
- ⭐ Модерация отзывов
- 🎉 Заявки на банкеты
- 📩 Сообщения с сайта
- 📊 Ежедневные отчёты
- 🎯 Воронки продаж (приветствие, брошенная корзина, после заказа)
- 🎂 Поздравления с ДР

---

## Деплой на Railway

### 1. Создайте бота
1. Откройте @BotFather в Telegram
2. Отправьте `/newbot`
3. Придумайте имя и username
4. Скопируйте токен

### 2. Узнайте свой Chat ID
1. Откройте @userinfobot в Telegram
2. Нажмите "Start"
3. Скопируйте ваш ID

### 3. Создайте проект на Railway
1. Зайдите на https://railway.app
2. Нажмите "New Project" → "Deploy from GitHub Repo"
3. Выберите репозиторий с этим ботом
4. Выберите папку `telegram_bot`

### 4. Добавьте переменные окружения
В настройках проекта добавьте:

| Переменная | Значение |
|------------|----------|
| `BOT_TOKEN` | Токен от BotFather |
| `ADMIN_CHAT_ID` | Ваш Chat ID |
| `WEBHOOK_URL` | `https://ваш-проект.up.railway.app` (опционально) |

### 5. Деплой!
Railway автоматически запустит бота.

## Локальная разработка

```bash
cd telegram_bot
pip install -r requirements.txt

export BOT_TOKEN="ваш_токен"
export ADMIN_CHAT_ID="ваш_id"

python bot.py
```

## Воронки продаж

| Воронка | Триггер | Сообщения |
|---------|---------|-----------|
| welcome | Новый пользователь | 2 (сразу + через 1 час) |
| abandoned_cart | Брошенная корзина | 2 (30 мин + 24 часа) |
| after_order | После заказа | 2 (2 часа + 7 дней) |
| birthday | День рождения | 1 (в день ДР) |

## Интеграция с сайтом

Бот принимает JSON-сообщения с сайта:

```json
{
  "type": "new_order",
  "order_id": "123",
  "customer": {"name": "Иван", "phone": "+79991234567"},
  "items": [{"name": "Шашлык", "quantity": 2}],
  "total": 1200
}
```

Типы событий:
- `new_order` — новый заказ
- `new_review` — новый отзыв
- `new_booking` — заявка на банкет
- `contact_message` — сообщение с формы
